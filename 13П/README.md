# Инструкция

Для работы, Вам нужен git. Его можно установить из Интернета на Windows и через пакетный менеджер на Linux.

После установки, клонируйте репозиторий:

```bash
git clone https://github.com/doccnova/practicalWorks.git
```

В данной папке создайте папку со своей фамилией:
```bash
mkdir "ФИО"
```
В эту папку закидываете все файлы проектов под конкретными именами, или, если проект раздроблен на несколько файлов, в отдельную папку.

Затем, добавьте и закиньте файлы в репозиторий:
```bash
git add .
git commit -m 'Добавил(a) n'
git push -u origin main
```

Учтите, что GitHub не даст вам войти по паролю через консольный Git, и нужно будет сгенерировать токен доступа.

Для этого, перейдите в Настройки GitHub > Параметры разработчика > Личный токен доступа > Токен (классический) > Сгенерировать новый токен > Новый токен (классический)

В открывшемся окне, выберите всё, что под аббревиатурой `repo`, а затем, в самом низу, нажмите Создать токен. Сразу же скопируйте его и сохраните на файле внутри внешнего носителя, т.к. больше вы этот токен не увидите.

Когда, после `git push -u origin main`, у вас попросит имя пользователя и пароль, вводите имя пользователя (например doccnova) и тот самый токен.
